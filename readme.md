Установка

1. Установить Python 3.10
2. Установить PycharmCommunity
3. Клонировать репозиторий git clone https://github.com/InnaLik/test_nesisi_bot.git
4. Установить зависимости командой pip install -r requirements.txt
5. Создать бд в соответствии с файлом db.py (использование любой СУБД/
   в данном проекте используется sqlite)
6. Получить токен через BotFather в телеграмме
7. Создать файл test_token.txt и добавить туда полученный токен
8. Зарегистрировать и получить токен с OpenWeather
9. Записать полученный токен в файл api_weather.txt
10. Подставить id чатов в ответные сообщения, где это необходимо
11. Запустить без дополнительных параметров
12. PROFIT
